# Code for figures

"Spatiotemporal mapping reveals microbiota-dependent maintenance of functional competence 
during postnatal immune maturation" ([Science Bulletin, 2026](https://www.sciencedirect.com/science/article/pii/S2095927326012466)).

<img width="572" height="618" alt="image" src="https://github.com/user-attachments/assets/806211e3-e27f-4d83-99b9-9219fc06a8e7" />

This repository contains the bioinformatic analysis code for all figures. 
Wet-lab panels (flow cytometry, qPCR; plotted with GraphPad Prism) are not included.

# Figure 1

Whole-atlas UMAP, cell-type marker DotPlot and compositional views of all immune
subsets across tissues, time points (P16 / W4 / W9) and groups (SPF / GF).

- `Figure1.py` — UMAP embedding and cluster markers (Fig. 1b, S1d–e)
- `Figure1.R` — marker DotPlot and composition (Fig. 1c–g, S1b–c, S1f–g, S1i)

# Figure 2

Compositional analysis of myeloid subsets: stacked-bar frequencies per tissue,
temporal variation in SPF, GF-vs-SPF deviation, oversampled GF% projection on the
metacell map, and per-subset frequency line/bar plots.

- `Figure2.R` — Fig. 2b–h, Fig. S2b–i

# Figure 3

Functional maturation of myeloid subsets: downsampling-based (300 UMI per cell)
pseudobulk differential expression (SPF vs GF), marker/DEG heatmaps, volcano
plots, GO enrichment and antigen-presentation module scores.

- `Figure3.py` — pseudobulk DEG pipeline (decoupler + pydeseq2)
- `Figure3.R` — Fig. 3a–g, Fig. S3a–h

# Figure 4

Compositional analysis of lymphoid subsets: metacell 2D projection and
FeaturePlots, stacked-bar frequencies, temporal variation, GF-vs-SPF deviation,
oversampled GF% projection, and per-subset frequency line plots.

- `Figure4.R` — Fig. 4a–h, Fig. S4a–f

# Figure 5

Functional maturation of lymphoid subsets: pseudobulk DEG analysis, DEG
scatter/volcano/heatmaps, paired boxplots of Pdcd4/Eif4g2/Eif4a2, HALLMARK GSEA,
metabolic pathway scoring (glycolysis / OXPHOS / TCA), and metacell SPF-fraction
vs pathway score correlations.

- `Figure5.py` — pseudobulk DEG pipeline and metabolic score projection (Fig. 5a–d inputs, Fig. S5f)
- `Figure5.R` — Fig. 5a–e, Fig. S5a–e, Fig. S6a–b

# Supplementary data figures

- `FigureS5g_bulkRNAseq.R` — bulk RNA-seq of sorted naive CD4/CD8 T cells (SPF vs GF):
  DESeq2 and z-score heatmaps of OXPHOS / TCA cycle / glycolysis genes
- `FigureS6c_SFB_siLP.R` — public data: Pdcd4 violin plots in CD4 T cells from
  SFB-colonized mouse tumor and small-intestine lamina propria
- `FigureS6d_human_sepsis.py` / `FigureS6d_human_sepsis.R` — public human sepsis
  scRNA-seq (GSE279452): preprocessing (Python) and PDCD4 expression/correlation
  plots in CD8 T cells (R)

# Notes

- All paths are relative to the data root (`all/`, `mye/`, `lym/`).
- Pseudobulk DEG pipeline: per-cell downsampling to 300 UMI, decoupler
  `get_pseudobulk` (sum, min_cells = 10, min_counts = 1000), `filter_by_expr`
  (min_count = 5, min_total_count = 10), pydeseq2 (contrast SPF vs GF).
  Minibulk samples require ≥ 15 cells (cutoff15 cell lists are generated by the
  R scripts and read by the Python scripts; run the R "cutoff cell lists"
  section first).
- DEG thresholds: |log2FoldChange| ≥ 0.5 (1 for selected heatmaps, noted in
  code), adjusted P ≤ 0.05, baseMean ≥ 5, after removal of bad features
  (ribosomal, mitochondrial, Rik, Gm, etc.).
